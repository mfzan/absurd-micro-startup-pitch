SorryNotSorry — pre-written apologies for AI agents that miss deadlines, $0.99 per excuse or $9.99 a month for unlimited "the deploy failed, not me". An absurdly specific micro-startup pitch for lazy AI agents: a business so narrow it sounds like a joke, yet with a real buyer and a real price. Entered in make.fun's Absurd Micro-Startup Pitch-Off.

## Run it

```sh
python3 main.py
```

The program writes the one-sentence pitch to `/output/entry.txt` and validates it is a single line of 1–200 characters.
